│       │   │                                • Scores: title, meta desc, canonical,
│       │   │                                          headings, keyword density,
│       │   │                                          schema, links, images, robots
│       │   │                                • Returns: { score: 0-100,
│       │   │                                           subscores: {...},
│       │   │                                           findings: [...] }
│       │   │
│       │   ├── geoAnalyzer.js              [GEO (Generative Engine) Pipeline]
│       │   │                                • Scores: chunkability (RAG-friendliness),
│       │   │                                          semantic HTML ratio,
│       │   │                                          citation density (stats/quotes/entities),
│       │   │                                          direct-answer block,
│       │   │                                          JS-dependency penalty
│       │   │                                • Returns: { score: 0-100,
│       │   │                                           subscores: {...},
│       │   │                                           extractedSignals: {...},
│       │   │                                           findings: [...] }
│       │   │
│       │   ├── llmCitationSimulator.js      [LLM Simulation (Claude)]
│       │   │                                • Sends raw content to Claude API
│       │   │                                • Asks: "Would you cite this as a primary source?"
│       │   │                                • Enforces strict JSON schema
│       │   │                                • Graceful fallback if API fails
│       │   │                                • Returns: { wouldCite, citationConfidence,
│       │   │                                           primaryTopic, coreEntities,
│       │   │                                           extractableClaims,
│       │   │                                           likelyQueryMatch, citationRisks,
│       │   │                                           reasoning }
│       │   │
│       │   └── suggestionsEngine.js         [Findings Merger & Prioritizer]
│       │                                    • Combines SEO + GEO findings
│       │                                    • Merges LLM citation_risks
│       │                                    • Ranks by severity (critical > warning > minor)
│       │                                    • Returns: { summary, seoFixes, geoFixes, quickWins }
│       │
│       │
│       ├── routes/                          [═══ EXPRESS ROUTES ═══]
│       │   │

│       │                                    [GET /api/analyze/stream?url=... (SSE)]
│       │                                    • Orchestrates: crawl → SEO → GEO → LLM → suggestions
│       │                                    • Streams progress via SSE

│       │

================================================================================
                            DEPLOYMENT TARGETS
================================================================================

Frontend (apps/web)
├─ Build: npm run build:web → apps/web/dist/
└─ Deploy: Cloudflare Pages (free tier, high availability, CDN)

Backend (apps/api)
├─ Runtime: Node.js 20+
├─ Process: pm2 or systemd
├─ Reverse proxy: Nginx/Caddy (TLS termination)
└─ Host: Ubuntu VPS (AWS, Linode, DigitalOcean, etc.)


================================================================================
                           QUICK FILE REFERENCE
================================================================================

Modify design?               → tailwind.config.js + components/*.jsx
Add SEO check?               → seoAnalyzer.js (add scoring function)
Add GEO check?               → geoAnalyzer.js (add scoring function)
Swap LLM (Claude → Gemini)?  → llmCitationSimulator.js (modify fetch call)
Remove LLM entirely?         → llmCitationSimulator.js (heuristic fallback) + routes/analyze.js
Change API host?             → PUBLIC_API_BASE_URL env var (frontend build)
Customize rate limiting?     → server.js (express-rate-limit config)
Add new metric to gauge?     → ScoreGauge.jsx (SVG paths, ticks, labels)
Change component styles?     → component.jsx (Tailwind classes) + tailwind.config.js (tokens)


================================================================================
                              INSTALL & RUN
================================================================================

# Install dependencies (both apps)
npm install

# Backend only (port 8787)
npm run dev:api

# Frontend only (port 4321)
npm run dev:web

# Build frontend for production
npm run build:web

# Check that everything is packaged
unzip -l geo-seo-analyzer-complete.zip
